## Structure

Every exercise gets its own folder, following Exercism's standard layout:

```
exercise-name/
├── .exercism/       # Exercism metadata (config, docs)
├── HELP.md          # Exercism's generic help file
├── README.md        # Exercise instructions
├── exercise_name.py       # My solution
└── exercise_name_test.py  # Provided test suite
```
